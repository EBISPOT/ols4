# Entity integration fixture

This five-record fixture extends the disposable PostgreSQL harness with the smallest data set that
can exercise all four `V2EntityController` routes. It is synthetic and contains no production or
internal data.

- Two active EFO classes distinguish label, definition, ranking, subset, and reverse-relationship
  behaviour.
- One active DUO class supplies a second ontology and distinct facet/filter values.
- One active EFO property proves that the generic entity route includes every supported entity
  type and that an explicit `type=class` filter narrows it.
- One obsolete EFO class proves the default and opt-in obsolete contracts.

The wrapper fields map to production `ols_entities` columns; `json` is the compressed API document
returned by `OlsSearchClient`. Schema and dynamic filter columns continue to be generated by
`dataload/create_postgres_schema.py`. Update wrapper and JSON values together, then run the Java 17
backend `verify` lifecycle with Docker available.
